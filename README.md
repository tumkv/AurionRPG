
# Подземелье Ауриона

Автор: Кузяков Владислав

## Описание

Подземелье Ауриона - текстовая RPG на Python.

Игрок управляет героем, сражается с монстрами,
использует зелья здоровья и пытается победить
финального босса.

Цель игры - пройти три комнаты и получить
артефакт Гильдии.

## Требования

Python 3.
Сторонние библиотеки не требуются.

## Запуск

Откройте терминал в папке проекта и выполните:

python main.py

## Управление

1 - атаковать противника.
2 - использовать зелье здоровья.
3 - посмотреть характеристики персонажа.

## Проверка 1: обычный сценарий

Ввод: имя героя, команды атаки и лечения.

Ожидаемый результат:
персонаж наносит урон, получает урон,
восстанавливает здоровье и может победить
монстров.

Фактический результат:
Игра успешно запустилась. Персонаж атакует
противников, наносит обычный и критический урон.
Зелья восстанавливают здоровье, не превышая
максимальное значение HP. После победы над
тремя монстрами появляется сообщение о победе.

## Проверка 2: необычный сценарий

Ввод: неправильная команда, например "abc".

Ожидаемый результат:
программа сообщает о неверной команде
и повторно предлагает выбрать действие.

Фактический результат:
При вводе команды "abc" программа выводит
сообщение "Неверная команда! Попробуй снова."
и повторно предлагает выбрать действие.
Игра не завершается, здоровье персонажа
не уменьшается, ход не тратится.
